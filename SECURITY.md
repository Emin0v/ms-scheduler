# Reporting a vulnerability

Use [private vulnerability reporting](https://github.com/Emin0v/ms-scheduler/security/advisories/new) for suspected security issues. Include the affected commit, prerequisites, impact, and a minimal reproduction. Remove credentials and personal data from examples.

Please use public issues for ordinary bugs and setup questions. These are example applications; no support window or response deadline is guaranteed. Passing CI or a clean scan does not establish that an application is safe to deploy in a particular environment.
